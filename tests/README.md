
### 不想装 bash？等价 curl 命令（cmd / PowerShell 可直接粘）

```bash
curl -s http://localhost:8080/api/health

curl -s -X POST http://localhost:8080/api/auth/login -H "Content-Type: application/json" -d "{\"username\":\"student01\",\"password\":\"123456\"}"

curl -s "http://localhost:8080/api/rooms"

curl -s "http://localhost:8080/api/rooms?minCapacity=10"
```

> Windows cmd 下 JSON 里的双引号需写成 `\"`；PowerShell 若报引号解析错误，
> 用 `curl.exe` 并把整段 `-d` 参数用单引号包起来。

## 二、跑种子数据校验

```bash
mysql -u root -p --default-character-set=utf8mb4 meeting_room < tests/sql/01_verify_seed.sql
```

脚本含 8 段校验，其中第 6、7 段是**半开区间 `[start, end)` 的教学与预演**：

- 第 6 段：列出「主楼 A301 / 2026-10-14」的占用时段，可见 `09:00-10:00` 与 `10:00-11:00`
  是两条独立记录——**首尾相接不算冲突**。
- 第 7 段：把 FR-09 的冲突判定写成 SQL（`start_new < end_old AND end_new > start_old`）。
  默认参数 `11:00-12:00` 期望 **0 行**（相邻不冲突）；改成 `10:30-11:30` 期望 **1 行**。

下面先把**冲突检测**的用例骨架列出来，第 9～10 周实现 FR-09 时直接照着写自动化测试。

> 判定规则：新预约 `[start_new, end_new)` 与已有预约 `[start_old, end_old)` 冲突
> ⟺ `start_new < end_old` **且** `end_new > start_old`。
> 约定的已有预约：`[09:00, 10:00)`。

| # | 新预约区间 | 与已有预约关系 | 期望 | 状态 |
|---|------------|----------------|------|------|
| C1 | `[08:00, 09:00)` | 首尾相接（前） | **不冲突**，允许提交 | 待补 |
