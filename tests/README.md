## 2. 后端单元 / 集成测试在哪

Maven 约定测试代码必须放在被构建模块内部，才能被 `mvn test` 执行，所以：

- **后端单元测试**：`backend/src/test/java/com/meetingroom/`
  - 已有一条零依赖用例：`common/ApiResponseTest.java`（不连数据库，任何机器都能跑）
- 运行方式：进入 `backend/` 执行 `mvn test`
- **实测状态（2026-10-12）**：✅ 已在本机跑通——`Tests run: 3, Failures: 0, Errors: 0`，`BUILD SUCCESS`

## 3. 第 7 周计划（对应第 6 周《周推进计划》§6.4）

按第 7 周测试计划，最小测试用例集覆盖三条线：

1. **登录**：账号密码正确 / 密码错误 / 账号被停用 / 参数为空
2. **查询**：无条件 / 按位置 / 按人数 / 停用会议室不出现在前台（FR-06）
3. **冲突检测**（★核心，半开区间 `[start, end)`）：
   - 重叠 → 冲突
   - 相邻（前一条 `end` == 后一条 `start`）→ **不算冲突**
   - 包含 / 被包含 → 冲突
   - 跨天预约 → 拒绝（FR-08）
   - 时长超过 8 小时 → 拒绝（FR-08）
   - 并发提交同一时段 → 只成功一条（事务 + 行锁）

> 冲突检测属业务功能（FR-09），按第 6 周口径"本周不写业务代码"，故以上用例在第 7～10 周逐步补齐。
