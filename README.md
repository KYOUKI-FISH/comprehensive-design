## 5. 第1周初步问题

1. 冲突根源：当前会议室超时占用和“僵尸预约”（预订未到）的频率有多高？背后原因是规则不清、系统提醒不足，还是执行不严？
2. 设备体验：投影/视频会议设备故障平均修复时长是多少？用户在会前能否提前感知设备状态？
3. 信息透明度：员工能否实时看到会议室空闲时段及设备完好情况？当前查询路径是否便捷？

## 6. 调研对象

A类 - 行政管理员 负责排期、审批、保洁、设备报修 需要后台管理权限、可视化看板、违规统计
B类 - 高频预订者（销售/项目组） 每周使用≥3次，常需连续多时段 需要快速预约、一键续会、冲突自动协调
C类 - 偶发使用者（财务/HR等） 每月使用≤2次 需要傻瓜式操作、清晰指引、移动端友好

说明：V1.0系统只要求实现普通用户和管理员两类角色；第三类为调研对象或后续扩展对象。
