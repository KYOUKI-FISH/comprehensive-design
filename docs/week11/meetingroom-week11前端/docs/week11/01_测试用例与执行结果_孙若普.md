## 3. 逐条执行记录

### TC-07 普通用户调用管理员“全部预约”接口

- 前置：mock 已启动；user001、admin001 已登录。
- 请求：

```http
GET /api/admin/bookings HTTP/1.1
Host: localhost:8080
Authorization: Bearer <user001 令牌，已脱敏>
Accept: application/json
```

- 响应：

```http
HTTP/1.1 403 Forbidden
Content-Type: application/json; charset=utf-8

{"code":40304,"message":"无权访问管理功能","data":null}
```

- 判定：状态码 403；`data` 为 `null`；响应体不含 `reservationNo`、`operationType`、`课题组周会` 等管理数据标记。
- 证据：`docs/week11/取证/02_越权查看/01_请求.txt`、`02_响应.txt`、`03_库内数据.txt`、`result.json`。
- 结论：**通过**。

### TC-08 普通用户查操作日志

- 请求：

```http
GET /api/admin/logs HTTP/1.1
Host: localhost:8080
Authorization: Bearer <user001 令牌，已脱敏>
```

- 响应：HTTP 403，`{"code":40304,"message":"无权访问管理功能","data":null}`。
- 库内核对：管理员接口回读日志总数 0 → 0，未被普通用户读出，也未发生越权写入。
- 证据：同 TC-07 的 `docs/week11/取证/02_越权查看/`。
- 结论：**通过**。

### TC-09 1366×768 与移动视口适配

执行方式：`npm run test:week11:compat`（Edge 156，Playwright 移动视口模拟）。

| 视口 | 列表页 scrollWidth / innerWidth | 详情页 scrollWidth / innerWidth | 查询按钮 | 进详情 | 控制台错误 |
|------|--------------------------------|--------------------------------|----------|--------|-----------|
| 1366×768 | 1366 / 1366 | 1366 / 1366 | 可点 | 可点击并进入详情 | 0 |
| 375×667 | 375 / 375 | 375 / 375 | 可点 | 可点击并进入详情 | 0 |
| 768×1024 | 768 / 768 | 768 / 768 | 可点 | 可点击并进入详情 | 0 |

说明：

- 375×667 下 7 列表格保留 **720px 最小宽度**，在 `.table-wrap` 内横向滚动，页面本身不横向溢出；操作列需在表格内横向滑动后点击。这是第 11 周修复的缺陷 **BUG-11-03**，详见 `05_Bug日志_孙若普.md`。
- 三个视口的 `requestfailed` 均为 0（过滤导航取消产生的 `net::ERR_ABORTED`），无加载失败的网络请求。
- 截图：`docs/week11/适配截图/Edge_1366x768_列表.png`、`Edge_375x667_列表.png`、`Edge_768x1024_列表.png`，以及对应的 `_详情.png`。
- 结论：**通过**。

### TC-12 我的预约只返回本人记录

- 执行方式：user001、user002 分别 `GET /api/bookings/mine`，再用管理员 `GET /api/admin/bookings` 建立 `id → username` 对照。
- 结果：

| 账号 | 我的预约条数 | 记录 ID | 状态 |
|------|--------------|---------|------|
| user001 | 3 | 2、3、5 | PENDING |
| user002 | 2 | 1、4 | PENDING、FINISHED |

- 断言：user001 的每条记录在管理端都属于 `user001`；user002 同理；两组 ID 无交集；所有状态属于 `PENDING/ONGOING/FINISHED/CANCELLED`。
- 证据：`docs/week11/取证/api-result.json` 中的 `TC-12`、`TC-12-status` 检查项。
- 结论：**通过**。
