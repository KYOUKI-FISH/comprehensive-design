## 7. 已知限制与边界

1. **mock 不是正式后端**：数据在内存，重启即重置；令牌也在内存，重启后旧令牌失效。正式后端的事务、行锁、编号生成、BCrypt、MySQL 落库由组员负责。
2. **本文的“库内数据”是接口回读**：mock 没有 MySQL；正式复跑必须用 `02_非功能与破坏性测试记录_孙若普.md` §6 的 SQL 重做，不能直接把本目录的回读截图当数据库证据。
3. **Chrome 未安装**：TC-11 只完成 Edge 分支；安装 Chrome 后重跑 `npm run test:week11:compat` 即可补齐，不需要改代码。
4. **375px 表格是容器内横向滚动**：页面本身不横向溢出，但操作列需要表格内滑动；卡片式移动布局留到第 12 周，不在功能冻结周做界面改造。
5. **正式部署三步未在本目录执行**：`mysql < schema.sql`、`mvn spring-boot:run` 依赖组仓库的后端与数据库；本目录只验证“前端 + mock”三步。干净机复现由李牧远执行。
6. **没有新增功能、没有改表结构、没有改接口契约**：本轮只修依赖版本、文案与 CSS 最小宽度，符合第 11 周功能冻结要求。
