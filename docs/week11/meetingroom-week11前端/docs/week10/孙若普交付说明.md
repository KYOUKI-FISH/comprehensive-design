## 1. 交付范围

对应《周推进计划_第10周》§0.1、§3 中孙若普负责的部分：

3. 前端错误提示统一为中文业务提示（NF-10）；

5. 管理员四步在页面上跑通；

## 4. 关键取舍

1. **管理员没有“我的预约”入口**：按角色说明权限矩阵执行，管理员处理预约走“全部预约处理”。
2. **状态不在前端推导**：四态全部读后端 `status`，避免浏览器时间与服务器时间不一致。
3. **30 分钟只做按钮禁用**：最终拒绝以后端为准，前端不把校验当安全边界。
4. **全部预约只做会议室/日期筛选**：按计划主动砍掉按用户/状态的多维筛选（FR-19 简化版），没有做半成品。
5. **管理页只做最小可用**：列表 + 增删改启停 + 日志查询，不做分页、批量、导出。
6. **mock 只用于联调**：不冒充正式后端，不把内存数据当验收证据。

## 7. 现场演示建议

1. 按 README 三步启动，浏览器打开 `http://localhost:5173`；
2. 从 mock 启动日志复制 user001 随机口令，按“普通用户八步”走；
3. 第 7 步修改时选明天的预约，避免触发 30 分钟限制；
4. 第 8 步取消后回详情页，指给验收人看 12:00–13:00 已恢复空闲；
5. 退出后用 admin001 登录，按“管理员四步”走；
6. 强制取消先点一次“确认强制取消”不填原因，展示被拒，再填原因成功；
7. 打开操作日志，展开任一记录给验收人看变更前后 JSON。
