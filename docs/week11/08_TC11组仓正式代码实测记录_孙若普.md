## 3. 三步启动与启动判据

### 3.1 数据库

```bash
# 1) 初始化并启动便携 MySQL（ASCII 路径，避免中文路径截断参数）
mysqld --basedir=C:/Users/Zhui_/week12-runtime/mysql-8.0.29-winx64 \
       --datadir=C:/Users/Zhui_/week12-runtime/mysql-data \
       --port=3306 --character-set-server=utf8mb4 \
       --collation-server=utf8mb4_unicode_ci --default-time-zone=+08:00

# 2) 导入建库/建表/种子（schema.sql 自包含）
cat docs/week07-08/schema.sql | mysql -h127.0.0.1 -P3306 -uroot -p
```

灌入后种子数据：3 个用户（admin / user1 / user2）、3 间会议室（逸夫楼A101、逸夫楼A202 启用；图书馆B301 停用）、7 条历史预约、1 条管理员操作日志。

### 3.2 后端

```bash
export JAVA_HOME="C:/Users/Zhui_/Desktop/智能会议/toolchain/jdk-17.0.21+9"
export DB_USERNAME=root
export DB_PASSWORD='<本次临时口令>'
mvn -s C:/Users/Zhui_/week12-runtime/settings-aliyun.xml \
    -Dmaven.repo.local=C:/Users/Zhui_/week12-runtime/m2repo \
```

使用 Aliyun 镜像与独立本地仓库，只是为了绕开 Maven Central 在本机的超时重试；**没有改代码包内的 `pom.xml` 或任何配置**。
