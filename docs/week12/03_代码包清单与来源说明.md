## 3. 明确排除的内容

| 排除项 | 原因 |
|--------|------|
| `backend/target/`、`frontend/dist/` | 构建产物，可由源码重新生成 |
| `frontend/node_modules/` | 依赖目录；用包内 `package-lock.json` 执行 `npm ci` 还原 |
| `.git/`、`.workbuddy/`、编辑器缓存 | 版本库元数据与本地工作数据，不属于交付物 |
| `__pycache__/`、`*.pyc`、`*.log`、`*.class` | 运行噪声 |
| `docs/week02～week12/` 历史周材料、测试报告、证据、`docs/答辩/` | 文档类材料在课程仓库中查阅，不塞进代码包 |
| 预答辩用 PPT | **四样中单独一项，不在代码包内**；当前尚未入库，见 `02_第12周预答辩推进计划.md` §1 |

## 4. 启动与校验

1. 解压后先读根 `README.md` 的「三步快速启动」：建库 → 起后端 → 起前端，共三步。
2. 判据：访问 `/api/health`，返回体中数据库状态为 UP 即启动成功。口令由环境变量提供，包内无明文口令与默认值。
3. 完整性校验：对 zip 计算 SHA-256，与本文表头的值比对；解压后按 §2 核对文件数与逐项字节数。
4. 抽查可当场重跑的脚本在 `tests/week11/`：并发 50、性能基线、灌数、攻击套件；使用方法见 `docs/week11/02_非功能与破坏性测试记录.md`。
