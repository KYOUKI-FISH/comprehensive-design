## 4. 启动与校验

1. 解压后先读根 `README.md` 的「三步快速启动」：建库 → 起后端 → 起前端，共三步。
2. 判据：访问 `/api/health`，返回体中数据库状态为 UP 即启动成功。口令由环境变量提供，包内无明文口令与默认值。
3. 完整性校验：对 zip 计算 SHA-256，与本文表头的值比对；解压后按 §2 核对文件数与逐项字节数。
4. 抽查可当场重跑的脚本在 `tests/week11/`：并发 50、性能基线、灌数、攻击套件、九组冲突与 BUG-08 设备模拟复测；使用方法见 `docs/week11/02_非功能与破坏性测试记录.md`。
