# DESIGN.md — 智能会议室管理系统 V1.0 答辩

## 场景与目标

- 场景：高校课程实践项目结题答辩（学术风 academic），受众：任课教师与评审组
- 目标：10–12 分钟讲清「需求怎么定 → 架构怎么搭 → 细节怎么落 → 验证到什么程度」
- 页数：20 页（封面 + 目录 + 4 章节扉页 + 13 内容页 + 封底）

## 全局视觉约定

### 画布与安全区
- 1280×720；左右 padding 60px（内容区宽 1160px）
- 顶条（深蓝实色）高 76px，绝对定位铺满；内容从 y=96 开始，到 y=640 结束
- 页脚固定 y=660：左「智能会议室管理系统 V1.0 · 第 4 组答辩」，右「NN / 20」
- 封面 / 目录 / 章节扉页 / 封底：无顶条、无页脚

### 字体与字号
- 中文：Microsoft YaHei（无思源黑体环境，取最接近的黑体）；西文/数字：Arial
- 封面主标 60；章节大数字 200；顶条主标 34；卡片小标 24；正文 20；表格 17；脚注 14
- 层级：Bold / Regular 两档

### 视觉母题
- 顶条左侧主标题 + 右侧「NN · 章节英文名」
- 卡片一律白底 + 1px `#D6DCE5` 描边（不用阴影、不用圆角大填充）
