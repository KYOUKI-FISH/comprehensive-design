## 4. Edge 端到端覆盖（46 项）

`scripts/e2e.mjs` 自己拉起 mock(18080) + Vite(5199)，用本机 Edge 在 1440×900 下执行，关键断言：

### 4.1 登录与角色

- 未登录访问 `/rooms` → `/login?redirect=/rooms`；
- 登录页有系统名称，无“注册/忘记密码”入口；
- 错误口令 → “账号或密码错误”；
- `user001` 登录 → 6 间会议室（接口数据，非前端假数据）；
- 普通用户菜单只有“会议室查询、我的预约”，无任何管理入口（FR-02）；
- 停用账号登录 → “账号已停用”；
- 登出 → 本地令牌清空，再访问受限页要求登录；
- `admin001` 登录 → 四个管理入口，无“我的预约”；
- 管理员详情页不显示预约按钮，显示“管理员账号不参与预约”；
- 普通用户访问 `/admin/users` → 403 页面。

### 4.2 查询与详情

- 按名称 `301` → 3号楼301；
- 按最小容量 `100` → 学术报告厅（120 人）；
- 按位置 `3号楼` → 3号楼301；
- 位置填“不存在的位置” → “未找到符合条件的会议室”；
- 详情页显示会议室名称、位置、容量、设备（基本信息来自列表接口，D1）；
- 选择明天 → 显示种子占用 10:00—11:00，同时显示空闲时段；
- 可用会议室显示“去预约”按钮，并把第一个空闲时段带入预约表单。

### 4.3 预约

- 从详情页进入表单 → 会议室、日期/时间已带入；
- 缺主题/人数/联系人时，对应输入框下显示行内错误（NF-09）；不跳页、不显示原始错误码；
- 预约 10:30—11:30 → 409；页面显示“该时段已被占用”和“2026-10-27 10:00 — 11:00”；
- 冲突后主题/人数/联系人原值仍在（FR-18）；
- 改为 11:00—12:00 → 成功，预约编号 `MR202610270004`（符合 `MR + 12 位数字`）；
- 成功后从接口再查占用：10:00—11:00 与 11:00—12:00 两条共存，证明首尾相接不冲突且新记录可查；
- 刷新页面 → 不掉登录，仍在当前页，用户信息保留。

### 4.4 分辨率与巡检

- 1366×768：页面无横向溢出，角色菜单完整可见、不被遮挡；
- 1920×1080：同上；
- 页面可见文本未出现本学期禁写 9 项；
- 浏览器控制台无脚本报错；无失败的网络请求。

## 5. 自测中发现并修复的问题

这三个问题是自测真正抓出来的，不是“事后补写”：

| # | 现象 | 根因 | 修复 | 证据 |
|---|------|------|------|------|
| 1 | 会议室列表按容量筛选时页面无反应，控制台 `TypeError: filters.minCapacity.trim is not a function` | Vue 对 `<input type="number">` 的 `v-model` 会自动转成数字，代码却按字符串调 `.trim()`；预约表单的“参会人数”同样存在该问题 | `RoomListView.vue` 与 `BookingView.vue` 统一用 `String(value).trim()` 归一化后再校验 | 修复前 E2E 在容量筛选处超时；修复后 46 项通过 |
| 2 | 详情页点“去预约”只带日期，预约表单起止时间为空 | 主“去预约”入口只传 `roomId/date`，没有传 `start/end`；`applyQueryPrefill()` 要求两者都有效才回填 | 主入口改为带入第一个空闲时段（与“用此时段预约”一致，最长取 1 小时），保证日期和时间都回填 | 修复前 E2E “预约表单带有详情页所选日期”失败；修复后通过 |
| 3 | 控制台有 favicon 404、登录 401/冲突 409 的资源错误 | 缺少 favicon；失败的 HTTP 请求会被浏览器记一条 resource error | 增加 `frontend/public/favicon.svg`；E2E 只过滤 400/401/403/409 的预期资源错误，脚本错误仍计入 | 修复后“浏览器控制台无报错”通过 |

另外，自测前把 mock 的演示口令从硬编码改为启动随机生成/环境变量注入，并让测试日志不输出可用口令，避免“仓库中有明文口令”的自检风险。

## 8. 未覆盖/不能替代的部分

1. **没有真实数据库**：mock 数据在内存；验收要求的 `SELECT * FROM reservation WHERE reservation_no=...` 必须在组后端/真实 MySQL 上补做。
2. **没有正式测试用例/报告**：本目录的 smoke/e2e 是开发自测，不替代第 11 周测试材料。
3. **没有并发测试**：NF-07 的 50 并发同一时段、行锁与唯一键冲突，属第 10/11 周范围；mock 是单进程串行，不能证明并发安全。
4. **没有完整日历视图**：详情页是时段列表，不是 FR-17 的完整日历/时间轴。
5. **没有管理页面与“我的预约”**：本周占位，第 10 周补。
6. **组后端契约未实测**：本目录只与 mock 联调；与组后端联调后需重跑一遍登录→列表→详情→预约，并核对 `API契约假设.md`。
