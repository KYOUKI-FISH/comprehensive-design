## 5. 首次使用注意

**必须关闭并重新打开终端**，新窗口才会读到新的 PATH。当前已打开的窗口需要手动执行：

```powershell
$env:Path = "C:\dev\jdk-17\bin;C:\dev\apache-maven-3.9.16\bin;" + $env:Path
```

或用 Git Bash：

```bash
export JAVA_HOME=/c/dev/jdk-17
export PATH="/c/dev/jdk-17/bin:/c/dev/apache-maven-3.9.16/bin:$PATH"
```

### 5.1 已知坑：Git Bash 里 `mvn` 报「找不到主类」

现象：

```
错误: 找不到或无法加载主类 org.codehaus.plexus.classworlds.launcher.Launcher
```

**这不是安装问题。** 原因：`bin\mvn`（shell 脚本）与 `bin\mvn.cmd`（Windows 批处理）在 Git Bash 下的路径解析差异，Git Bash 把 `mvn` 解析到 shell 脚本后，classworlds jar 路径没被正确转换。

三种解法任选其一：

1. **在 PowerShell 或 CMD 里跑**（推荐，最省事）：
   ```powershell
   mvn -B test
   ```
2. Git Bash 里显式调 `.cmd`：
   ```bash
   mvn.cmd -B test
   ```
3. Git Bash 里用完整路径：
   ```bash
   /c/dev/apache-maven-3.9.16/bin/mvn.cmd -B test
   ```

### 5.2 跑后端前必须设 `DB_PASSWORD`

第 9 周起 `application.yml` 已去掉默认口令，**不设变量后端启动会失败**：

```powershell
$env:DB_PASSWORD='你的MySQL口令'; cd backend; mvn spring-boot:run
```

> 注意：`mvn test` 用的是单元测试（Mockito），**不需要连数据库**，所以本记录中的 30 条测试是在**没有配置 MySQL 口令**的情况下跑通的。要跑真实联调才需要设 `DB_PASSWORD`。

## 6. 如何卸载

```powershell
# 1) 删用户变量
[Environment]::SetEnvironmentVariable('JAVA_HOME', $null, 'User')

# 2) 从用户 PATH 移除两项（或用「系统属性 → 环境变量」界面手删）
$p = [Environment]::GetEnvironmentVariable('Path','User')
$p = ($p -split ';' | Where-Object { $_ -notmatch 'C:\\dev\\(jdk-17|apache-maven)' }) -join ';'
[Environment]::SetEnvironmentVariable('Path',$p,'User')
```

然后删除 `C:\dev\jdk-17`、`C:\dev\apache-maven-3.9.16`、`C:\dev\setup-java-maven-path.ps1` 即可。
如需彻底清理，再删除 `C:\Users\25407\.m2`（含所有已下载依赖，约数百 MB）。
